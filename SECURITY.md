# Security Policy

This repository contains the open-source Skills Layer CLI and local integration surface only. Skills Layer Cloud, marketplace services, Guardian scoring internals, and hosted backend code are not part of this repository.

## Reporting A Vulnerability

Please do not open public issues for active vulnerabilities.

Use GitHub private vulnerability reporting for this repository when available, or email `hello@skills-layer.com` with a short non-sensitive summary and a way to contact you securely.

Include:

- affected package version
- operating system and Node.js version
- steps to reproduce
- impact and any suggested mitigation

We prioritize issues that could expose credentials, bypass Guardian checks, corrupt local installs, or mislead users about the source of a package.
